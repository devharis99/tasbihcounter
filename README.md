# 🕌 Islamic Tasbih Counter

A modern, responsive, and spiritually inspired **digital tasbih counter** to assist Muslims in performing **Dhikr** (remembrance of Allah ﷻ) from any device. Built with pure HTML, CSS, and JavaScript.

## 🌟 Features

- 🧮 Simple counter for tasbih
- ➕ Increment / ➖ Decrement buttons
- 🔁 Reset option
- 🔢 Step selector: +1, +5, +10, +20, +50, +100
- 💾 Saves your progress using localStorage
- 🕌 Islamic-themed background & styling
- 📱 Fully responsive (mobile/tablet/desktop)
